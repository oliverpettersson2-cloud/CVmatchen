# Pilot-erbjudande till Arbetsmarknadsförvaltningen, Helsingborg

**CVmatchen — AI-driven jobb- och CV-plattform byggd av en SYV i Helsingborg.**

---

## Erbjudandet

| | |
|---|---|
| **Vad** | Full tillgång till CVmatchen för en utvald enhet inom AMF |
| **Period** | 3 månader (90 dagar) |
| **Pris** | **5 000 kr/månad** — totalt 15 000 kr för hela piloten |
| **Antal användare** | Obegränsat inom pilotenheten |
| **Support** | Direktkontakt med grundaren (Oliver Pettersson, SYV Helsingborg) |
| **Sedan?** | Efter pilot diskuterar vi direktupphandling för bredare införande |

> **15 000 kr ligger väl under direktupphandlingsgränsen** (700 000 kr för kommuner 2026) — inget upphandlingsförfarande krävs.

---

## Vad ingår

✅ Hela deltagar-vyn (CV-bygge, AI-coach, jobbmatchning, 105 träningsmoduler, intervjuträning)
✅ Hela handläggar-vyn (deltagar-överblick, uppgift-tilldelning, statistik, CV-nedladdning)
✅ Onboarding av era handläggare (~30 min)
✅ Personuppgiftsbiträdesavtal (PuB)
✅ All data lagrad inom EU (Stockholm, Frankfurt, Irland)
✅ AI via AWS Bedrock i Frankfurt — ingen USA-överföring
✅ Zero data retention — er data tränar inte AI-modeller
✅ GDPR-radering inbyggd
